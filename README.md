# ChunkPatch

Fabric 1.19.4 單人世界工具模組。它會讀取世界存檔中的 Anvil 區域檔與 Chunk NBT `Status`，依 Xaero World Map 的實際門檻顯示可繪、未達標與缺少的區塊，允許查看、輸入或拖曳設定邊界，然後把缺少或過早階段的區塊生成到 `FEATURES`。

## 功能

- `K` 開啟全螢幕預覽介面；可用滾輪縮放、拖曳平移，並顯示游標所在方塊與區塊座標。
- 掃描目前維度的 `region/*.mca` 位置表，不修改既有區塊。
- 將每個區域檔的判讀結果快取於實例的 `config/chunkpatch-scan-cache`；首次仍須完整掃描，掃描中會定期建立安全檢查點，之後只重掃大小或修改時間有變動的 `.mca`。
- 掃描使用低優先序專用執行緒，並在同一個區域檔內重用 zlib 解壓器，避免大型世界首次掃描產生大量原生資源與 GC 壓力。
- 綠色顯示世界存檔已達可繪製的 `features`／`light`／`spawn`／`full` 階段，橘色顯示尚未達到 `features` 的半成品，黑色顯示未生成區塊，紅色顯示異常資料。放大到約 1 區塊 1 像素以上時逐區塊精確著色；縮小檢視時改以縮略統計密度著色；生成時即時更新並以青色標示目前進度游標。
- 掃描與生成都會依目前實際速度顯示預估剩餘時間與大約完成時刻；暫停時間不會計入生成 ETA。
- 自動偵測最遠邊界，也能拖曳黃框或輸入方塊座標。
- 估算完整、未完成、異常與待生成區塊數量後才允許開始。
- 生成採嚴格「單一進行中」的非阻塞模式：同一時間最多只有一個區塊在生成，前一個完成後才會提交下一個，不在伺服器 tick 內同步等待，避免大範圍未生成地形一次展開造成長時間卡頓。提交下一個目標前會檢查伺服器平均 tick 時間與記憶體使用率，負載過高時自動暫緩。
- 低於 2 GiB 可用空間時阻止或自動暫停。
- 每批儲存世界與進度，重新啟動後會依當下世界實際狀態重新核對並續跑（不依賴可能過期的暫存進度）。
- 不重做已達 `features` 的綠色區塊，也不自動處理標記為異常的區塊；合法半成品會由 Minecraft 接續生成到 `features`，玩家日後走近時再由原版完成到 `full`。

## 使用方式

1. **只在世界備份上使用。** 預生成會永久擴大世界存檔。
2. 將建置出的 JAR 放入 Fabric 1.19.4 實例的 `mods` 資料夾。
3. 進入要處理的單人世界與維度，按 `K`。
4. 按「掃描世界」。
5. 查看預覽；滾輪縮放、拖曳平移，並可拖曳黃框或輸入東西南北的方塊座標。
6. 按「套用並估算」，檢查待生成數量。
7. 按「開始生成」。介面不會暫停單人世界。
8. 完成後退出並重新進入世界，在 Xaero World Map 執行 `Reload Regions`；需要多人地圖輸出時再執行 `Convert All Regions`。

## 備援指令

```text
/chunkfill scan
/chunkfill status
/chunkfill pause
/chunkfill resume
/chunkfill stop
/chunkfill start <西界X> <東界X> <北界Z> <南界Z>
```

指令座標使用方塊座標。單次選取面積安全上限為 5,000,000 個區塊。

## 建議的 JVM 記憶體設定

生成前的記憶體閘門是看「已用／`-Xmx` 上限」的比例（超過 85% 暫緩，低於 75% 恢復）。如果把 `-Xmx` 設得遠超過實際需求（例如主機有 64 GB 就直接給 25～32 GB），同樣的尖峰配置量在比例上會顯得很小，閘門可能不會即時反應。建議：

- 一般驗證／單機使用：`-Xmx8G`。
- 較大型模組整合包：`-Xmx10G` 左右，依實測用量調整。
- 不要只因為主機記憶體夠大就給到 25 GB 以上；沒有證據顯示更大的 heap 對穩定性有幫助，反而會讓同一波配置尖峰在比例上更不容易被閘門偵測到。

## 判讀黑色區域

- 模組預覽為綠色，但 Xaero 顯示黑色：世界區塊已存在，應先使用 Xaero `Reload Regions`。
- 模組預覽為橘色：世界存檔只有低於 `features` 的 ProtoChunk，Xaero 會拒絕建立像素，可由本模組補到 `features`。
- 模組預覽也為黑色：世界存檔中沒有該區塊，可由本模組生成。
- 模組預覽為紅色：區域檔位置表異常，本模組會保留現況並拒絕覆寫。

## 建置

```powershell
.\gradlew.bat build
```

輸出位於 `build\libs\ChunkPatch-<版本號>.jar`。
