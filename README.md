# ChunkPatch

Fabric 1.19.4 單人世界工具模組。它會讀取世界存檔中的 Anvil 區域檔，顯示已存在區塊與缺口，允許查看、輸入或拖曳設定邊界，然後只生成邊界內真正缺少的區塊。

## 功能

- `K` 開啟全螢幕預覽介面；可用滾輪縮放、拖曳平移，並顯示游標所在方塊與區塊座標。
- 掃描目前維度的 `region/*.mca` 位置表，不修改既有區塊。
- 綠色顯示已儲存區塊、黑色顯示未生成區塊、紅色顯示異常位置表項目；生成時即時更新並以青色標示目前進度。
- 自動偵測最遠邊界，也能拖曳黃框或輸入方塊座標。
- 估算既有、異常與待生成區塊數量後才允許開始。
- 每 Tick 生成 1～8 個區塊，預設 1。
- 低於 2 GiB 可用空間時阻止或自動暫停。
- 每批儲存世界與進度，重新啟動後可續跑。
- 不覆寫既有完整區塊，也不自動處理標記為異常的區塊。

## 使用方式

1. **只在世界備份上使用。** 預生成會永久擴大世界存檔。
2. 將建置出的 JAR 放入 Fabric 1.19.4 實例的 `mods` 資料夾。
3. 進入要處理的單人世界與維度，按 `K`。
4. 按「掃描世界」。
5. 查看預覽；滾輪縮放、拖曳平移，並可拖曳黃框或輸入東西南北的方塊座標。
6. 按「套用並估算」，檢查待生成數量。
7. 按「開始生成」。介面不會暫停單人世界。
8. 完成後退出並重新進入世界，在 Xaero World Map 執行 `Reload Regions`；需要多人地圖輸出時再執行 `Convert All Regions`。

## 備援指令

```text
/chunkfill scan
/chunkfill status
/chunkfill pause
/chunkfill resume
/chunkfill stop
/chunkfill start <西界X> <東界X> <北界Z> <南界Z> [每Tick區塊數]
```

指令座標使用方塊座標。單次選取面積安全上限為 5,000,000 個區塊。

## 判讀黑色區域

- 模組預覽為綠色，但 Xaero 顯示黑色：世界區塊已存在，應先使用 Xaero `Reload Regions`。
- 模組預覽也為黑色：世界存檔中沒有該區塊，可由本模組生成。
- 模組預覽為紅色：區域檔位置表異常，本模組會保留現況並拒絕覆寫。

## 建置

```powershell
.\gradlew.bat build
```

輸出位於 `build\libs\ChunkPatch-0.1.2.jar`。
